# Project status

Garage Design is feature-complete for its current scope and is in release-maintenance mode.

## Completed

- Rectangular garage modeling with configurable front-door openings
- 250 original, customizable tile layouts
- Mouse, touch, pen, and keyboard painting
- Front-right tile anchoring with cuts moved to the back and left
- Verified drainable-product comparison
- Package, waste, leftover, ramp, Illinois tax, and shipping calculations
- Browser-local saved plans with migration support
- PNG and print-report export
- Docker-only development, testing, and build workflow
- Responsive desktop, accessibility, unit, and Chromium workflow coverage

## Maintenance priorities

1. Recheck product prices, availability, colors, ramps, and shipping policies before their dated
   catalog observations become stale.
2. Keep saved-plan migrations backward compatible.
3. Add new product options only when dimensions, drainage, colors, prices, and sources are verified.
4. Preserve the no-host-install Docker workflow.
5. Run the full verification and browser suites before a release.

## Possible future scope

- Obstacles such as lifts, cabinets, drains, columns, and stairs
- Irregular room shapes and wall recesses
- More destination-specific shipping rules
- Optional local tax configuration
- Additional verified drainable tile systems

These are ideas, not commitments. The current application should remain focused on producing a
clear, purchase-ready plan for rectangular garages.
